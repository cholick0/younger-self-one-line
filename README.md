A make.fun bounty entry: the single line I would send my younger self if one line were all I got.

> That haircut you are hiding under a cap will grow out, kid — but the apology you owe your mother will not, so say it tonight.

`main.ts` writes the line to `/output/entry.txt` (125 characters, one line, within the 1–200 gate) and reads it back byte-for-byte to verify.
